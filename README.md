# Sell House Fast

A lightweight property lead-generation landing page concept built around a simple homeowner journey: understand the offer, see the benefits, and take a clear next step.

## What this project demonstrates

- Conversion-focused landing-page structure
- Responsive HTML/CSS implementation
- Clear call-to-action hierarchy
- Property-focused messaging and trust sections
- Supporting information pages for contact, terms, and disclosures
- Static-site deployment that is easy to host and maintain

## Stack

- HTML5
- CSS3
- GitHub Pages / static hosting compatible

## Repository structure

- `index.html` — main landing page
- `about.html` — project/about information
- `contact.html` — contact page
- `terms.html` — terms
- `disclosure.html` — disclosure information
- `living-room.jpg` — hero imagery

## Purpose

This repository is a focused frontend experiment in property lead generation. It is separate from my larger property-platform work and is kept as a compact example of a direct-response landing page.

## Status

Portfolio / prototype project. The repository is public for demonstration and learning purposes.
